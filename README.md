# CertiFlow – Skilling Certificate Issuance Platform

## Project Overview

CertiFlow is a digital certificate issuance platform that enables training centres to submit candidate batches, district officers to review and approve batches, the state office to provide final approval, and candidates to receive certificates.

The platform provides secure approval workflows, certificate generation, asynchronous delivery, audit trails and public certificate verification.

## User Roles

- Training Centre
- District Officer
- Quality Team
- State Office
- Candidate
- Public / Employer

## Technology Stack

- Frontend: React + Vite
- Backend: Node.js + Express + TypeScript
- Database: PostgreSQL
- ORM: Prisma
- Cache and Queue: Redis + BullMQ
- Background Processing: Node.js Worker
- Containerization: Docker Compose
